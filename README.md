# ESFIDELIS Biosciences — Complete Website

A complete responsive static front-end website for the ESFIDELIS brand.

## Pages
- index.html — Homepage
- catalog.html — Research catalog
- product-retatrutide.html — GLP-3 Retatrutide 20 MG product record
- coa.html — Searchable batch / COA registry
- about.html — Brand story
- contact.html — Inquiry form
- disclaimer.html — Research and compliance disclaimer
- terms.html — Terms template
- privacy.html — Privacy template

## Included functionality
- Responsive desktop/mobile navigation
- Product catalog
- Product detail page
- Batch and COA search
- Product-aware inquiry form
- Mobile menu
- Branded hero image
- Legal/compliance starter pages

## Before publishing
1. Replace `info@esfidelis.com` in `script.js` with your real business email.
2. Replace all demonstration batch data with verified information.
3. Link each COA record to the actual third-party laboratory report for that exact batch.
4. Replace the placeholder legal text with language reviewed for your actual business.
5. Add your final domain, hosting, analytics, and form/CRM provider.
6. Do not advertise products for unapproved human use or make unsupported purity, medical, safety, or efficacy claims.

## How to preview
Open `index.html` in a browser.

This static site can be deployed to Netlify, Vercel, Cloudflare Pages, GitHub Pages, or a traditional web host.
